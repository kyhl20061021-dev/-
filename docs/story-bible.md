# Story Bible: 摆渡人·荒原之间

> 本文件为**最高设定**。任何剧本、关卡、系统设计与之冲突时，以本文件为准。
> 修改本文件需要作者本人确认，AI 不得自行增删设定。

## 一、 世界观设定 (Worldview)

*   **荒原 (The Wasteland)**：位于生与死之间的过渡地带。并非客观实体，而是**"心像的投射"**。荒原的地貌、天气、甚至危险程度，完全由穿越此地的灵魂（如迪伦）的内心情绪决定（如：恐惧时乌云密布，平静时阳光明媚）。
*   **摆渡人 (Ferryman)**：荒原的引路人。没有固定名字、样貌和过去。他们的样貌会变成"最能让灵魂产生信任感"的样子。职责是护送灵魂穿过荒原，躲避恶魔，抵达分界线。
*   **恶魔 (Demons)**：荒原中的捕食者，由堕落的灵魂聚集而成。通常在阴影处或黑夜出没，群聚攻击。一旦抓住灵魂，会将其拖入地下，导致灵魂彻底消散（魂飞魄散）。
*   **安全屋 (Safe House)**：荒原中唯一能阻挡恶魔的庇护所，位置固定，通常破败不堪，但在夜间是绝对的安全区。

## 二、 核心人物设定 (Character Profiles)

*   **迪伦 (Dylan)**：
    *   *生前背景*：15岁，单亲家庭，内向、聪慧、有些倔强。在去见生父的火车事故中死亡。
    *   *游戏标签*：感性、抗拒规则、驱动力（改变崔斯坦的契机）。
    *   *核心痛点*：渴望被爱，恐惧孤独；得知死亡真相后的绝望，以及为了爱敢于重返荒原的勇气。
*   **崔斯坦 (Tristan / 真实名字未知)**：
    *   *背景*：没有真正活过，一直处于引导灵魂的轮回中。见证过无数人性的自私与脆弱，变得冷漠、毒舌。
    *   *游戏标签*：理智、服从规则、外冷内热。
    *   *核心痛点*：从"工具"向"人"的转变。因迪伦而流血、不再变样（报废），恐惧自己无法跨过分界线，却用谎言骗迪伦离开。

## 三、 四幕情绪曲线 (Emotional Arc)

### 第一幕：安全屋逼问 (The Confession) —— 1~8章

*   **情绪基调**：未知 -> 恐惧 -> 崩溃 -> 接受。
*   **核心事件**：隧道相遇，破屋夜袭。恶魔的物理威胁逼迫崔斯坦说出真相（"你是唯一没有逃出来的人"）。
*   **玩家体验**：玩家在压抑的黑暗中产生极度的依赖感，随后面临"自己已死"的巨大情感冲击。

### 第二幕：荒原同行 (The Wasteland Journey) —— 8~20章

*   **情绪基调**：依赖 -> 怀疑 -> 心动 -> 决绝。
*   **核心事件**：两人在荒原穿行，经历沼泽、湖区、山谷。崔斯坦暴露出"不愈合的伤口"和"不改变的面貌"（报废征兆）。迪伦产生怀疑与爱意。
*   **玩家体验**：从单纯躲避恶魔的生存游戏，转变为对崔斯坦内心世界的探索，两人羁绊逐渐加深。

### 第三幕：分界线背叛 (The Betrayal) —— 第20章

*   **情绪基调**：甜蜜（顶点） -> 惊愕 -> 愤怒/心碎 -> 绝望。
*   **核心事件**：迪伦表白，崔斯坦回应"我爱你"。迪伦跨越分界线，回头却发现崔斯坦消失（单向玻璃）。
*   **玩家体验**：情绪过山车。利用"双视角互换"让玩家瞬间从"被背叛的愤怒"转变为"看着他捶墙却无能为力的极度虐心"。

### 第四幕：荒原逆行 (The Reversal) —— 20章之后

*   **情绪基调**：执着 -> 负罪（玛丽之死） -> 破釜沉舟 -> 脆弱的重逢。
*   **核心事件**：迪伦在记录室得知真相，独自返回荒原找崔斯坦。害死玛丽，找到崔斯坦，两人共同决定穿越回人间（来到隧道口）。
*   **玩家体验**：主动出击，反抗命运。在巨大的代价（可能魂飞魄散）下，完成对"爱能超越生死"的终极考验。
