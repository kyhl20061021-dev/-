# Glossary: 核心术语词典

> 本文件是**用词最高设定**。所有台词、UI 文案、注释必须遵守这里的称谓与禁用词。

## 一、 核心实体 (Entities)

*   **摆渡人 (Ferryman)**：引导灵魂穿越荒原的存在。绝对不要写成"死神"或"天使"，他们是执行规则的工具，没有灵魂和寿命概念。
*   **恶魔 (Demons)**：荒原的食腐者。不要用"丧尸"、"幽灵"形容。它们是黑色的旋涡、利爪、抓挠灵魂的冰冷触感、拖入地下的力量。
*   **灵魂 (Souls)**：死后的存在形态，在荒原中显化为生前的样貌，身体被留在现实世界的车祸现场。
*   **审判官 (The Judge)**：*(后期设定，为第二部铺垫)* 规则的监督者，裁决违规穿越的行为。

## 二、 地理与场景 (Locations)

*   **荒原 (The Wasteland)**：心像投射的世界。地貌随灵魂的心情变化（如迪伦的苏格兰高地景象）。
*   **安全屋 (Safe House)**：荒原中的避难所，统一特征为：门窗破损、有壁炉、破家具。恶魔无法进入，无论外面多吵。
*   **分界线 (The Boundary)**：荒原的尽头，通往"彼岸"。透明的、有一道光的墙。单向通行，摆渡人无法跨过。
*   **记录室 (The Archive)**：跨过分界线后的档案馆。存放所有摆渡人的"名册"，被划掉的名字代表被恶魔吞噬的灵魂。

## 三、 设定术语 (Concepts)

*   **心像投射 (Projection)**：荒原的本质。迪伦越害怕，路越难走；迪伦越开心，天气越好。
*   **灵魂完整度 (Soul Integrity)**：游戏内的生命值。代表灵魂在荒原的稳固程度，低于0即灰飞烟灭。
*   **单向玻璃 (One-way Glass)**：分界线对摆渡人的限制。摆渡人能看到灵魂离开，但灵魂回头看不到摆渡人。
*   **摆渡名册 (Ferryman's Ledger)**：记录崔斯坦摆渡过的所有灵魂的名字与死期。名字被划掉 = 任务失败。
*   **荒原逆行 (Reverse Journey)**：灵魂违背规则，从彼岸重新打破门回到荒原的行为。代价是极可能魂飞魄散。
*   **钴蓝色 (Cobalt Blue)**：崔斯坦眼睛的专属颜色。这是迪伦确认他没有改变、没有被规则重置的唯一标志。
