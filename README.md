# 摆渡人：荒原之间 · 第一幕原型（第 1–9 章）

网页 3D 叙事探索原型。Three.js + 原生 JavaScript + Vite。非商业学习用途。

**现在能玩到的**：从隧道口出发 → 沿小路走到安全屋 → 进屋发现三处对不上的细节 → 逼问崔斯坦 → 真相揭开（心跳停止、画面褪色、UI 改口）→ 限时抉择（崩溃 / 接受 / 沉默）→ 第一幕幕间卡 → Tab 回看另一视角 → 第 9 章山谷口限时选择 → 走错则坏结局并可回到选择之前。

---

## 运行

```bash
cd ferryman-3d
npm install        # 首次
npm run dev        # http://127.0.0.1:5178/
```

打包与测试预览：

```bash
npm run build      # → dist/
npm run preview    # → http://127.0.0.1:5179/   （dist 需静态服务器，不能直接双击 file://）
```

**只想玩、不想敲命令**：双击项目根目录的 `start-game.bat`（桌面上也放了一份 `Ferryman.bat`）。
它会先看 `dist/` 在不在，不在就构建；再看 5180 端口有没有服务，没有再起一个（最小化的黑窗口，关掉它游戏就停），最后用默认浏览器打开 `http://127.0.0.1:5180/`。

## 设定文档（最高指令）

`docs/` 下三份文档是这个世界观的**唯一权威**，任何剧本、关卡、系统与它们冲突时，以文档为准：

| 文件 | 管什么 |
|---|---|
| `docs/story-bible.md` | 世界观、迪伦与崔斯坦、四幕情绪曲线 |
| `docs/mechanics.md` | 视角解锁节点、QTE 形态、三条数值的增减逻辑 |

| `docs/AI-CONTRACT.md` | 下一任 AI 的读取顺序、六条红线、代码地图 |

**给 AI 用的开场白**：

```
先读 docs/story-bible.md、docs/mechanics.md、docs/glossary.md，
再读 docs/AI-CONTRACT.md，然后才开始回答。
```

文档里的规则不是靠自觉遵守的——`npm run check` 会把它们变成 **89 条断言**（隔离 14 + 设定 75，见下文）。

## 已完成功能

### 场景
- 程序化生成 244×244 低多边形荒原地形（值噪声 fbm + 边缘丘陵抬升）
- 一条从隧道口通往安全屋的小路：地形沿路自动整平、顶点色改为土色
- **植被（Unity《Meadow Environment》资源包）**：白桦 / 橡树 / 桦树灌木 / 三种草 / 地被 / 高草 / 五种花 / 岩石群 / 原木 / 栅栏 / 蘑菇，全部转成网页格式后实例化
  - 分布不靠随机撒点，靠一层**低频「肥力噪声」**：只有肥力高的地块才长草长树，其余保持裸露，于是画面自然形成大片空地 + 小片残余植被
  - 再叠一层高频噪声让草**成丛**，同时给任何位置保留约 6% 的零星植株，避免出现「像没做完」的全空地块
  - 模型只取 LOD0、按材质拆件，顶点已归一化到「最长边 = 1」，实例缩放即真实米数；总量约 14.6 MB（模型 9.1 MB + 贴图 5.5 MB，45 个 prefab / 53 个部件 / 32 张贴图）
- 隧道口拱门 + 内部黑暗、门框碎石
- **可进入的安全屋**（5.62 × 4.6 × 2.9 m）：四堵实心墙 + 一个门洞 + 门楣 + 双面屋顶（抬头能看到天花板）。室内有壁炉（三层锥体火苗 + 光强呼吸）、桌子与碗、带框窗（玻璃 + 边框 + 中竖挺）
  - 碰撞从「一整块矩形」改成 **5 段矩形**：前墙拆成门洞左右两段，于是门是真能走进去的
  - 第三人称镜头在室内会**沿「头→镜头」射线收缩**（`cameraRig._pullIn`），而不是直接夹坐标——直接夹会变成俯视 + 满屏墙皮；室内同时不渲染玩家自己
- 天空：星点 520（压到几乎看不见）、淡月 + 光晕、11 座远景山影。基调是**阴天的苍白天光**而不是深夜：天空 `0x64747c`，亮到能看清地形，仍保留荒原的灰
- 雾：FogExp2 0.0066，雾色 `0x7b8990` 比天空亮一档，远处泛白形成纵深，约 120m 外只剩剪影
- 浮尘粒子 420（缓慢漂移）
- 光照：半球光 2.75 + 环境光 1.2 + 主平行光 2.25（带 2048 阴影贴图）+ 冷色补光；壁炉暖光实时闪烁
- 后处理感：ACES 色调映射（曝光 1.74）+ CSS 暗角（边缘 0.44，跟着恐惧值加深）

### 角色与操作
- 低多边形人物由基础几何体拼装（约 14 个部件），带程序化走路摆臂 / 摆腿 / 起伏
- 玩家角色：WASD 相对相机方向移动、Shift 奔跑、速度平滑加减速、朝向插值
- 第三人称：镜头跟随 + 平滑、地形防穿 + 室内包围盒收缩
  - **镜头位置与视线解耦**：镜头本体只在安全绕行区间（-72°～+7°）里绕，视线按真实俯仰角单独算。原因是物理的——镜头在头后 4.6m，想抬头就得降到比头低，再低就钻地，以前一抬头就被地面卡死。解耦之后抬头能到 77°，天真的会进画面
  - 上下不做 360° 是结构性的：左右是绕竖轴，转多少圈都不出问题；上下越过 ±90° 就是球坐标极点，画面会瞬间翻面
- 第一人称：眼高 1.62m、隐藏自身模型、准星
- 碰撞：圆形障碍推挤 + 矩形障碍（含门洞的 5 段墙体）+ 世界边界
  - **位移按 0.12 m 分步推进**（`moveWithCollisions`），每步解一次碰撞。一帧位移超过墙厚时推挤式碰撞会「从墙前跳到墙后」，掉帧或切标签页回来就会穿墙——分步之后不会了
  - 第三人称镜头也做**扫掠避障**（射线 vs 墙的矩形 / 大石的圆），贴着房子转身时镜头会被拉到墙外，而不是「透」进墙里看到一整块墙皮
- NPC：站定等待 / **带路（lead）** / 跟随（follow）。带路时目标点是「玩家斜前方 3.2 m + 侧向 1.25 m」，侧向偏移是必须的——正前方会挡死镜头；进屋自动切回贴身跟随，否则 5.6 × 4.6 m 的空间放不下「前方三步」

### 叙事：第 1–9 章
- **三处疑点**（`hotspots`，第 7 章）：火（烧着却没有人添柴）、碗（干净得不像用过）、窗（外面没有雨声）。三处都观察过，才能对崔斯坦开口
- **真相在第 8 章**由一句台词置位，不是旁白解释：
  > 「你不是唯一活下来的人。你是唯一没有出来的那个。」
  同时触发 `heartstop` 效：环境音被抽空 0.22 秒、只留心音、画面降饱和变透明（`body.reveal`）
- **UI 措辞跟着剧情改口**：真相之前那条状态叫「气息」，之后才叫「灵魂完整度」——否则 UI 本身就是剧透
- **限时选择**：选项摆出来才开始计时（`timeLimit`），条走完由 `timeoutChoice` 代选。第 8 章超时**不是失败**，是「沉默」这条分支
- **失败与回溯**：`checkpoint` 标记的选择点，走错进坏结局（`failures.stay` / `failures.walk_on`），结尾给「回到选择之前」——回溯整体覆盖 flags / done / chapter / stats / pos / yaw / mode，**数值一起回滚，不惩罚读者**
- **幕间卡**：第一幕结束的结算页（标题 + 正文 + 是否出现另一视角入口）
- 对话系统：打字机效果、说话人着色、选项分支、键盘 1-3 选择、`line.chapter` / `line.effect` 支持逐句推进章节与特效
- 触发器：圆形范围、一次性、可要求前置剧情标记
- 存档：两条线各自独立 localStorage 键；菜单显示已有进度，可一键清除
- **自动存档点**：`checkpoint` 的选择点会快照到 `state.checkpoint`

### 「另一视角」回看（按视角解锁规则）
- 第 1–8 章单线；**第 8 章读完才出现入口**（`pov.unlockAt = 8`）
- 第 9–19 章不加新的双视角入口；第 20 章才强制切换（`pov.forcedSwapAt = 20`）
- 入口只做**回看**，不自动跳转、不改主线（`pov.autoOpen = false`）；始终可选，随时进出
- 内容恰好 8 章、每章不超过 4 行，全部是**内心片段**，不解释事实、不补充设定
- 面板：左列章节目录 + 右列正文，`src/ui/pov.js`

### 数值与心像投射（按 docs/mechanics.md 实现）
- **三条轴**，全部定义在 `src/core/canon.js`：
  - 灵魂完整度（迪伦专属，100 起，被触碰 -10，真相 -10，恐惧天气 -1%/分钟，安全屋 +4%/分钟）
  - 信任与羁绊（共用，0 起，选项加/减，60 为「高羁绊」门槛）
  - 报废度（崔斯坦专属，荒原上被动 +0.5/分钟）
- **数值写在剧情数据里**，不在代码里：`dialogue.fx` / `line.fx` / `choice.fx`
- **心像投射**：紧张时雾浓 34%、月光压暗 20%、暗角加深；羁绊升高时雾色掺一点暖；第 8 章分支结算会改天气（`mood.setBias`）
- **钴蓝色瞳孔**：不受光照的 Basic 材质，夜里也能认出那一点钴蓝

### 双线信息隔离（重点）
- 两条线各有独立数据文件：`src/data/route-dylan.js` / `route-tristan.js`，共用同一份世界
- 迪伦线 **147 条**文本经静态检查确认不含任何解释性词汇（死 / 灵魂 / 摆渡人 / 恶魔 等）
- 崔斯坦线可以出现「完整 / 裂痕」这类知情描写，但不得知道迪伦没告诉他的私事
- 隔离由两处强制：`npm run check:isolation` 静态扫描 + 运行期读取 `dialogue.transcript` 二次校验

### 环境音
- WebAudio 合成：滤波噪声风声 + LFO 阵风 + 48Hz 低频底噪，无需任何音频文件
- **程序化心跳**：两下 thump + 间隔随 tension 变化（1.12s → 0.72s）；`heartStop()` 把环境音抽空后只留心音，`reviveHeart()` 恢复

## 已知问题（未完成 / 有妥协的部分）

1. **无头浏览器截图不可靠**：headless Chrome 下 WebGL 合成层截不到（曾因此得到全黑截图）。视觉验证必须用真实窗口。
2. **窗口被遮挡会让 rAF 停摆**：前置一个 `--disable-features=CalculateNativeWinOcclusion` 之类的启动参数才能稳定跑自动测试（已写进 `tools/flow-ch8.mjs`）。
3. **不要给全屏遮罩加 `backdrop-filter`**：全屏模糊盖在 WebGL 画布上会把合成器拖死——表现是截图挂起、帧不再推进、测试莫名卡住。已踩过一次，注释留在 `styles.css` 里。
4. **角色是占位模型**：几何体拼装，无骨骼、无面部表情，走跑动画步频一致。
5. **NPC 寻路是直线的**：只有碰撞推挤，没有绕行。
6. **没有敌人与威胁**：三条数值已接入，但扣除只来自剧情事件与「恐惧天气」，还没有恶魔追上来——QTE 属于第二幕。
7. **没有天气与昼夜循环**：固定「阴天白昼」的基调；「恐惧导致天气变坏」目前只表现为雾浓、雾色转冷与暗角加深。
8. **第 10–19 章是空的**：目前只写到第 9 章山谷口。第 9–19 章按视角规则不加双视角入口，内容待写。
9. **存档不记录对话进度**：只存标记、位置与数值；已播完的对话通过标记判断。
10. **室内构图上有一处将就**：崔斯坦跟随时会贴到镜头前，真相那场他的头被画面右缘切掉一截。正确做法是进屋后让他停在门口并转身，而不是继续跟随（属美术/调度问题，不影响判定）。
11. **移动端未适配**：需要键盘鼠标。
12. 打包体积 560 kB（含 three.js），已忽略 Vite 的 chunk 警告。
13. **调试接口暴露在 `window.__game`**：传送、捕获画面、施加数值效果、重置终局等，正式发布前应移除。
